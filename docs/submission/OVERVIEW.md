# Hackathon overview

**One compromised login should not erase your way back.**

**Status:** Following the organisers' outage guidance, sign-in, roles and governance
are simulated. Archive bytes and scoped transactional purge are real application
functionality. Live Tide cryptographic protection remains unverified.

**Vision and originality** — Make recovery-copy deletion a governed act, not a standing
admin privilege. Each request freezes one version, recipient and 30-minute window.

**Trust constraint** — The intended guarantee is that one compromised application account
cannot manufacture destructive authority. Distinct simulated trustee actor IDs count once
each; locally selectable accounts do not establish independence between people.

**Value and impact** — Synthetic logistics firm Harbourline Freight can delegate archive
maintenance without intending to delegate unilateral destruction of recovery copies.

**Why Tide matters** — The intended integration governs issuance of the exact
`vault-purge:<manifest hash>` realm role through Tide IGA. The trusted backend checks
scope, recipient, issuer, client, expiry and single use. The real signed policy and
alternative grant paths still need verification. Local voting is not equivalent cryptography;
server/root compromise is outside the demonstrated boundary.

**Prototype and storytelling** — File without deleting bytes; show first/repeated votes
insufficient; grant after a distinct second simulated trustee; purge exactly once; reject
replay and download the surviving version. A terminal demonstration illustrates the same
vault core with unsigned synthetic claims, separately from HTTP/auth testing.
